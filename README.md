# Zest Landing Page 
Live URL:- https://zest-landing-page-one.vercel.app/

A responsive landing page for Zest, a fictional sparkling fruit drink
brand. Created as a frontend development and UI/UX portfolio project.

## Stack

- Semantic HTML through React TSX
- CSS
- JavaScript behaviour written in TypeScript
- React
- TypeScript
- Vite
- Oxlint

## Features

- Responsive navigation with a mobile menu
- CSS product illustration
- Interactive three-flavour selector
- Product preview and description updated through React state
- Responsive ingredient cards
- Native HTML FAQ disclosure controls
- Skip link and visible keyboard focus
- Reduced-motion support for colour transitions

## Run locally

npm install
npm run dev

## Checks

npm run lint
npm run build

## Preview the production build

npm run preview

## Design decisions

A cream background, bold typography, and colourful product previews
give the fictional brand a playful identity.

The flavour selector demonstrates typed product data, array mapping,
event handling, and React state.

The FAQ uses native HTML details and summary elements for built-in
disclosure behaviour.

## Scope

This is a frontend-only concept.

There are no real products, verified formulations, payments, orders,
or backend services. Ingredient descriptions are illustrative.
